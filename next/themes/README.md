# Bundled themes

Ghostty-format theme files built into termhop-next, so `theme = Catppuccin Mocha` works without copying anything.

Colors are from [Catppuccin](https://github.com/catppuccin/catppuccin) (MIT License, Copyright (c) 2021 Catppuccin),
in the file layout of [iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes) (MIT License), which Ghostty ships.

Other Ghostty themes can be used by copying the file into a `themes` folder next to `next.conf`.
